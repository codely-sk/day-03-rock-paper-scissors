# ✊ Rock Paper Scissors — Day 03

**Project 3 of Project 20 | 20 Days · 20 Python Projects**

A simple command-line Rock Paper Scissors game built with Python as part of my personal challenge to complete 20 projects in 20 days.

## 📌 About the Project

This is a game where the player competes against the computer by choosing rock, paper, or scissors. The program randomly selects the computer's choice and uses conditional statements to decide the winner.

The game continues until the player chooses to quit.

## ✨ Features

- 🎮 Play against the computer
- 🎲 Random computer choices
- 🏆 Automatic winner and loser detection
- 🤝 Detects ties
- ⚠️ Handles invalid choices
- 🔁 Play multiple rounds
- 🚪 Exit the game using `quit`

## 🛠️ Technologies Used

- **Language:** Python
- **Module:** `random`
- **Concepts:** Lists, `random.choice()`, `while` loops, conditional statements, `if-elif-else`, logical operators, `break`, and `continue`

## ▶️ How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run the following command:

```bash
python day_03_rock_paper_scissors.py
```
